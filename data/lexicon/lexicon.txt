# 评论分析用词典
#
# 【为什么词典要单独存成文件，而不是写在 py 里】
# 三个理由，都是踩过或预判到的：
#
# 1. **可替换**。这份词典是有倾向的：它按"电商评论"这个语域手工整理，
#    换了行业（比如卖车、卖课）就得整套换。存成文件，换的时候不用改代码。
# 2. **可审计**。一个词被判成正面还是负面，用户有权查。
#    写在 3000 行的分析模块中间，没人查得到。
# 3. **可扩充**。jieba 的自定义词典是纯文本格式（词 词频 词性），
#    和情感词典放一起，一次加载，少一次 I/O。
#
# 格式说明见各段标题，jy 是 jieba 用户词典用的。

# 二·B、词云专用停用词（STOP_CLOUD）
# ============================================================
# 【这一节为什么必须和 [STOP] 分开】
#
# 上面 [STOP] 是给"情感打分"用的：它删的是"的/了/是"这类
# 对情感无贡献的虚词，删了不影响判断对不对。
#
# 但词云要回答的问题不是"这句话是好是坏"，而是
# **"用户在抱怨什么/夸什么"**。这两个问题需要的过滤规则不一样：
#
#   ① 情感词本身必须删。
#      "不好"在一个差评词云里出现 89 次，看起来是第一名，
#      但它没有告诉你任何东西——它只是把"这是差评"重复了 89 遍。
#      同理"不错"在所有词云里都排前三，因为它是中文评价里
#      最高频的褒义词，跟"这家店好在哪"完全无关。
#
#   ② 平台名 / 商品本体名必须删。
#      "京东"出现 197 次排第一，是因为这份语料是从京东抓的，
#      用户说"京东送货还行"是在说平台，不是在说商品。
#      "苹果"182 次同理——它是商品名，不是评价。
#
# 【为什么以前没发现】
# 因为词云"看起来"总是对的：一堆词、有的大有的小、
# 排第一的还挺像回事。要发现这个错，必须真的去读
# 前三名背后的原句——"京东送货还行"原句是夸物流的。
# 这就是模块头那句"点不出来的词都是耍流氓"的实际用处。
#
# 加词的门槛：一个词如果在**好评和差评里出现频率差不多**，
# 它对"区分问题"就没有价值，该删。

# 【轻正面：含否定字但整体是正面表态】
# 这几个在我第一版里被错放进"假朋友表"，理由听起来很合理——
# "含否定字，靠窗口翻转会算错"。
# 但屏蔽造成的损失比翻转错更大：它们是这些句子里唯一的情感信号。
#
# 实测：「香蕉奶味道还不错~就是太贵了」，5 星好评。
#   · 屏蔽 '不错' → 只剩 '太贵' → 判 -0.58 负向（错）
#   · 当正面词      → '不错'+1 与 '太贵'-2 对冲 → 判中性/轻负（对）
# 所以正确处理不是"忽略"，而是"给低权重"——它们确实是弱表态。
#
# 【权重定 0.6 而不是 1】
# 实测「不是很好，但也不差」整句只有 '不差' 一个命中，
# 权重给 1 时 tanh(1/3)=+0.32，超过 0.15 的中性阈值 → 判成正面。
# 但"不是很好，但也不差"的语义就是"一般"，判正面是错的。
# 0.6 让它在二元句里落在中性区间，在明确好评里（和其他正面词并列）
# 仍能贡献正向——这正是"轻正面"该有的行为。

# ============================================================
# 四、单字情感词（需上下文，权重减半）
# ============================================================
# 【为什么要单独一档，而不是直接删掉】
# 这批字确实有情感倾向，但**离开上下文就是歧义炸弹**。
# 实测本店 13,500 条的假阳性里，前十名有六个是它们：
#
#   脆  「是脆的，味道一般吧」            → 形容口感，好评；5 星
#       「速度超级棒，苹果也很脆甜可口」   → 好评；5 星
#   薄  「质料较薄，不知抗汗防晒怎样」     → 客观描述，不是抱怨
#   卡  「短信满了，也只能望卡兴叹」       → 名词！内存卡
#       「1G跑VIST…」                   → 型号
#   拖  「评论里面说的拖影确实是有」       → 名词，"拖影"
#   慢  「联大带小好多个瓶子，慢慢用吧」   → 副词，"慢慢"
#   差  「这个价位的质量还差不多」         → "差不多"，根本不带贬义
#
# 全部删掉会丢掉真实信号（"太薄了"、"卡得不能动"确实是差评）；
# 全部保留会把好评判成差评。所以做法是：
#   · 权重砍到 0.5（单字天然不如词组确定）
#   · 必须有上下文才计入：紧邻程度副词，或作独立 token 后接"了/的"
#   · 命中黑名单组合（差不多/慢慢/望卡…）直接跳过
[WEAK_SINGLE]
# 【这一节的词一律按"负面"处理，除了明确标 + 的】
# 这是个坑：我最初把 '好' 也丢进这一节，结果它被判成负面 ——
# 「包装很好，可惜压坏了」里 '好' 贡献 -0.5，

# 【下面这几个原来在假朋友表里，是放错了地方】
# 不错 / 不差 / 还行 / 还可以 / 不贵 / 不慢 / 不薄 ——
# 我最初的理由是"它们含否定字，靠窗口翻转会算错，干脆屏蔽"。
# 但屏蔽掉的后果更糟：这几个词本身明确是正面表态，
# 屏蔽等于把一条好评里唯一的情感信号扔了。
#
# 实测代价：「香蕉奶味道还不错~就是太贵了」，
# '不错' 被屏蔽 → 只剩 '太贵' → 整句判成 -0.58 负向，而这是 5 星好评。
# 正确做法是把它们当正面词（见 [POS] 的 "轻正面" 一段），
# 而不是当"不存在"。

# ============================================================
# 五之二、程度词遮蔽（先遮掉，再判否定）
# ============================================================
# 【这一节是这轮最严重的一个 bug 的修法】
#
# 症状：「面料不错，颜色正，我非常满意」  5 星好评
#       被判成 -0.435 负向。
#
# 追查：命中的负面词是「满意」，否定的来源写着 '非'。
#   '非常满意' 里的 '非' 被当成了否定词！
#   因为 [NEGATION] 里有单独的 '非'（"非卖品"里的非），
#   而否定判定是"在情感词前面 5 个字里找否定词"，
#   '非常' 的 '非' 完全落在窗口内。
#
# 这不是偶发：「非常好」「非常满意」「非常喜欢」「非常划算」
# 在语料里出现了几百次，每一次都被判成了负面。
# 而它错得特别隐蔽——单独看 '非' 确实是否定词，
# 逻辑上没毛病，只有跑真实数据才会发现"越夸越差"。
#
# 修法：判定否定之前，先把程度词整体遮掉。
# 遮的是"非常""特别"这类含否定字的程度词，
# 遮完再找否定词，'非常' 就不会再被当成 '非'。
#
# 【为什么不用"给非加边界条件"】
# 因为这类词不止一个：非常、特别（不含）、无比、无比…
# 逐个写例外条件会越写越多，而"先遮程度词再判否定"
# 是一条能覆盖所有情况的结构性修法。

# 六、否定词与程度副词
# ============================================================
# 【否定词为什么必须单独处理】
# "不好" 里有 "好"（正面），不做否定的情感分析会判成正面。
# 这是最经典也最致命的错误，而且它出错的方式很有欺骗性：
# 大部分句子没错，只在否定句上错，整体准确率看起来还行。
#
# 处理方式：向前看窗口 window=3 个词，命中否定词就把极性整体翻转一次。
# 为什么是 3：中文里"不太算是很好"这种多重否定很少见，
# 窗口开大会把前一句的否定误套到后一句上。
#
# 程度副词单独一档：它不改变正负，只调整幅度。

# 【弱否定的合词形式】
# '不太' '不怎么' '不够' 这几个被 jieba 各自粘成一个 token，
# 所以 '不' 单独一条永远匹配不上。
# 实测「不太满意，有点失望」被漏判成正向 +0.261 —— 用户明确说失望，
# 系统说他是满意的。这是情感分析里最不能接受的一类错。
#
# 【为什么'不太'按完全否定处理，而不做"程度减半"】
# 严格说"不太满意"比"不满意"轻。但情感分析在这里只需要判方向，
# 方向的错远比强度的错严重：
#   · 判成"负向但程度轻" → 业务上是对的（确实有问题，优先级低一点）
#   · 判成"正向"         → 业务上完全错（把抱怨当好评，永远不会处理）
# 强度差异靠 '有点' 这类程度弱化词来体现，不靠否定词自己。

# 七、转折词
# ============================================================
# 【转折词为什么值得单独一节】
# 中文差评的典型句式是"先夸后贬"或"先贬后夸"：
#   「质量不错，但是尺码偏小」    → 负面（用户真要说的在后面）
#   「有点小问题，总体还行」      → 中性偏正
#   「包装很好，可惜压坏了」      → 负面
# 转折词后面的分句是**真正的态度**，前面的只是铺垫。
#
# 处理方式：转折词之后的分句，权重乘 1.3；之前的分句乘 0.6。
# 不定成 2 倍是因为很多句子确实是"总体满意，一点小瑕疵"，
# 前后都真实。倍数太大会把这类句子一律判成负面。
#
# 这一条是我在做 5 星差评分析时发现的：大量 5 星评论里
# 有一句"但是/就是/就是有点"引出的小抱怨，
# 不分权重的话，这些句子会被夸的部分吃掉，导致漏判。
