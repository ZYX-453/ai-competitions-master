一、赛道解读：市场营销与客户洞察

官方定义：理解用户与市场，把数据、反馈和洞察转化为更好的营销与增长决策。

  • 用户画像 / VOC 分析 —— 从用户反馈中还原真实人群与真实诉求
  • 市场调研 —— 快速形成有依据的市场判断
  • 营销策略 —— 把洞察转成可执行的打法
  • 内容洞察 —— 看懂什么内容在打动谁

作品要求：从真实或模拟的管理场景出发，自主识别具体问题，把管理 Know-how 转化为可运行、可复用、可验证的 AI 工具（不是写一篇分析报告交差，而是交一个"能跑起来的东西"）。

二、硬性规则速览

参赛资格

  • 全国高校在读学生，可跨校组队
  • 每队 3–5 人，每人只能参加 1 支队伍
  • 鼓励跨学科：经管 + AI/技术 + 数据
  • 先完成报名，再提交作品
  • 截止日前可多次提交，以最后一次为准

时间线

  • 报名与作品提交：10月10日 – 11月10日
  • 校园路演与产品培训：10月12日 – 10月31日
  • 初赛评审（选 20 强）：11月11日 – 16日
  • 复赛线上路演（选 10 强）：11月21日 – 22日
  • 决赛线下路演答辩：11月底

合规红线（违反直接出局）

  • 核心产物必须在千问办公中生成，第三方工具只能辅助
  • 作品须原创或已获合法授权，且未在其他赛事获奖、未商业化
  • 数据来源合法，完成必要授权或脱敏
  • 保留关键对话、任务记录、阶段截图备查（Session ID 必须交）

奖励

三、评审维度 → 得分策略

评审维度怎么拿分
管理问题洞察与行业 Know-how选一个真实行业场景，用专业模型（KANO / STP / AARRR / 用户画像方法论）把问题讲透，别停留在"我觉得"。
AI 工具设计与 Vibe Coding 实现作品必须能跑：完整流程 + 演示视频。核心产物在千问办公里生成，全程留存 Session ID。
学生自主增量与创新性明确写出团队自定义的规则、公式、标签体系、流程框架——这是区分"让 AI 写个报告"和"团队做了个工具"的关键。
实际效果与验证质量用数据说话：效率提升百分比、标注一致率、改进前后对比。哪怕模拟数据，也要有对照实验设计。
通用性与落地潜力说清楚能复用到哪一类场景、换个行业怎么迁移、给谁用、怎么推广。

四、三个候选选题（附推荐）

选题 A · 推荐

用户之声（VOC）洞察与产品改进决策台

问题：新消费/电商品牌每天产生上千条评论、客服对话、社媒反馈，运营人工归类慢、口径不一，产品改进和营销话术缺数据支撑。

管理 Know-how：KANO 模型（必备/期望/魅力属性）+ NPS 归因 + Persona 用户画像 + VOC 五步闭环（采集→清洗→编码→归因→行动）。

作品形态：导入评论/对话文本 → 千问办公自动打标（情感 + 主题 + KANO 归类）→ 用户画像卡片 → 问题优先级矩阵（提及频次 × 情感强度）→ 自动产出《产品改进清单》《营销话术优化建议》+ 可视化看板。

自主增量：自定义行业标签体系、KANO 判定规则表、优先级加权评分公式、抽样复检机制。

验证设计：抽 100 条人工标注 vs 工具标注算一致率；分析耗时对比（如 4 小时 → 20 分钟）；拿一个模拟品牌（校园奶茶店 / 耳机品牌）跑全流程做前后对比。

推荐理由：管理 Know-how 最扎实、验证最好做、和官方案例（精准营销、营销复盘看板）差异化最明显。

选题 B

小红书内容洞察与选题策略工作台

问题：品牌做内容营销靠感觉选题，爆款难复制。

Know-how：内容漏斗、爆款拆解（钩子-价值-信任-行动）、人群×场景×卖点匹配。

形态：笔记数据 → 爆款结构拆解 → 选题日历 + 标题库 + 脚本框架 → 复盘看板。

验证：小规模实测或模拟对比互动率。

选题 C

轻量市场调研快反工具

问题：小团队做市场调研周期长、报告不专业。

Know-how：问卷设计原则、STP、用户画像、定价与渠道基础。

形态：问卷/公开数据导入 → 自动统计 → 画像 + STP 建议 + 策略报告 + 汇报 PPT 一键生成。

验证：与人工分析对比效率与结论一致性。

五、11 天倒计时行动计划

  • 10/30 – 10/31
    定选题、组齐 3–5 人队伍、完成报名；注册千问办公（赠 2000 积分）。
  • 11/1 – 11/3
    在千问办公里搭工具主流程，跑通最小可用版本；全程留存 Session ID 和阶段截图。
  • 11/4 – 11/6
    跑效果验证：做人工 vs 工具对照、效率对比、前后效果数据。
  • 11/7 – 11/8
    写作品描述（600–1600 字，7 个要点全覆盖）、录演示视频、画开发与迭代关键步骤图。
  • 11/9 – 11/10
    提交作品（预留缓冲，可多次提交以最后版本为准）；社媒带话题分享拿 1000 积分。
