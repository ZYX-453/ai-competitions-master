# 差评炼金炉 · 归因诊断 Agent

> 第一届中国 AI 管理实践挑战赛 ｜ 赛道一 ｜ 市场营销与客户洞察

一个能**自己决定查什么、查完再决定下一步**的退货归因系统。
不是套了壳的报表：它会推翻自己的假设，会在证据不足时直说，
会把"我算不出来"和"数据里没有"当成两件不同的事来讲。

## 三分钟跑起来

```bash
cd agent/backend

# Windows (cmd)
set CANYU_LLM_KEY=你的key
"C:\Program Files\Python311\python.exe" -m uvicorn main:app --port 8848

# macOS / Linux
export CANYU_LLM_KEY=你的key
python -m uvicorn main:app --port 8848
```

打开 <http://127.0.0.1:8848> 就是完整应用（前端产物已在仓库里，不用装 node）。

**没有 Key 也能跑。** 不设 `CANYU_LLM_KEY` 会走确定性模板，
结论、数字、判定全部一样，只是措辞没模型那么自然。界面右下角会标明当前是哪种模式。

Key 用阿里云百炼的（`sk-ws-` 开头）。换厂商设 `CANYU_LLM_BASE` + `CANYU_LLM_MODEL` 即可，代码不用动。

## 它跟"报表"差在哪

同一个问题「第 44 周为什么涨了」，两种系统的区别：

| | 报表 | 这个系统 |
|---|---|---|
| 回答 | 按原因列个占比表 | 先判是不是真异动（z 值 + 业务双门槛） |
| 遇到促销周 | 照旧归因到"破损变多" | 先拆机制与结构，发现是**促销改变了退货倾向**，不是质量变差 |
| 假设被推翻时 | 不会发生 | 抽样读原文后发现"尺码问题"其实是"同码不同大"，**推翻自己上一轮的结论** |
| 数据里没这一类 | 报错 / 空表 | 查本地知识库给通用方案，并明确标注"这是行业经验，不是本店数据" |
| 工具挂了 | 500 | 说"这次没读到"，而不是冒充"没有" |

最后两条是最近两轮才补上的，具体见 [agent/README.md](agent/README.md) 第 11、12 节。

## 数据从哪来

**两层来源，承担不同论证任务**，这一点是整份材料能不能站住的关键：

| 层 | 内容 | 用来证明什么 |
|---|---|---|
| 真实文本 | 2.15 万条电商评论（监控 13,500 + 训练 8,000） | 归因能力——模型面对的是人写的脏话、错别字、情绪 |
| 模拟面板 | 158 SKU × 52 周，含两级传导真值 | 方法可靠——因为**知道真值**，才能验证"算出来的因果对不对" |

模拟数据不是能力不足的妥协，是刻意设计：真实数据没有反事实，
你永远无法证明「发现了促销机制」这个结论是对的。详细的 DGP 设计和
参数回收检验见 [reports/README.md](reports/README.md)。

> ⚠️ 仓库里的 `data/processed/*.csv` 被 `.gitignore` 排除（最大的 9.9MB）。
> 需要数据请跑 `python scripts/build_dataset.py`（种子固定，产出完全一致）。

## 怎么核对（不用读代码）

```bash
cd agent/backend

python run_all.py            # 8 条行为用例：走对工具了吗、徽章对吗、数字编了吗
python check_complaints.py   # 12 条措辞用例：用户投诉过的那几句话回来了吗
python check_kb_fail.py      # 3 条故障用例：把知识库文件改坏，看它说不说假话
```

三套测的是三件不同的事，缺一不可：

- `run_all` 测**行为**——但测不出措辞。用户投诉的"样本量不足"发生在文案上，行为完全正常。
- `check_complaints` 测**说了什么**——把用户原话逐条重放，全文搜禁用语。
- `check_kb_fail` 测**坏了会怎样**——正常路径跑多少遍都测不到，因为故障不会自己发生。

最后一步是真的截图看。代码改了 ≠ 屏幕上没有。

## 已知局限

写在代码里，也写在这里：

1. **两类归因混在一个指标上**——数量传导和结构传导在面板上是同一个退货率，
   需要额外拆解才能分清。目前靠 z 值和促销机制校验，不是根本解法。
2. **知识库只有 8 类原因**——覆盖服饰/家居常见问题，生鲜的冷链、临期没做。
3. **模型偶尔算错减法**——实测过一次 13.75−13.53 写成 0.42。现在提示词强制
   "差值一律抄 `delta_pp`，不要自己减"，数字校验也会拦，但这是概率性防护。
4. **单店单周期**——没有跨店铺对比，也没有时间序列预测。
