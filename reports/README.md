## 这份数据集凭什么可信

### 1. 参数回收：把"模拟"从软肋变成地基

模拟数据最常被质疑的一句话是"结论是编出来的"。标准回应方式是**参数回收**
（parameter recovery）：在已知真值的世界里，看估计量能不能把真值找回来。

| 参数 | 含义 | 真值 | 估计值 | 相对误差 |
|---|---|---|---|---|
| λ₁ | 退货率 → DSR | 1.300 | 1.303 | **0.3%** |
| λ₂ | 二阶滞后 | 0.550 | 0.558 | 1.5% |
| ω₁ | DSR → 曝光 | 0.640 | 0.639 | **0.2%** |
| ω₂ | 三阶滞后 | 0.280 | 0.245 | 12.4% |

**4/4 全部通过 15% 阈值。** 且 ω₂ 这一项最弱（12.4%）、原因已定位（DSR 滞后两周与三周原始相关 0.895，效应被 ω₁ 吸收），**不隐藏、不删除**——留着它，正是为了说明这份检验不是"挑好看的报"。

配合两项稳健性检验：
- **安慰剂**：随机打乱滞后退货率后重估，λ₁ = −0.0029，t = 0.34，无显著效应 ✓
- **方法对比**：Pooled OLS 偏差 4.9% → 双向固定效应 0.3%，收缩 94%

### 2. 全部真值公开，随机种子固定

`dgp_params.json` 里写着每一个生成参数的真值。**"编数据"的人不会公开真值**——
公开了就等于承认这是模拟，而不公开则是学术不诚实。这份材料选择前者。

种子固定为 `20261110`，`python build_dataset.py` 可完整重建，逐字节一致。

### 3. 21 处缺陷全部留档

报告第十章逐条记录了 21 处从 v1 到 v2.3 的修正，包括几处如果没查出来会直接毁掉作品的：

- 目标函数写错（退货时也扣补偿 → 所有情形 c\*=0）
- 金标准全部来自训练集且答案写在列里（κ 必然接近 1）
- 退货率方程没有类目项（数码反超服饰，与行业事实相反）
- 补偿与毛利被绑死（把因果识别做坏，误以为"补得多更有效"）
- 单位换算差 100 倍（算出"月 GMV 增长 130%"）
- 生鲜出现七天无理由退货（违反《消法》第二十五条）
- 图 5 图与图注打架（相差 29 倍）
- 图 7a 口径差 100 倍（"毛利率 12000%"）

**多数参赛队不会展示 bug 修复史。** 这份材料把它当作数据严谨性的证据。

## 两个方法论级的发现

这两条不是"修 bug"，而是从数据结构里自然浮现、可以直接立论的结论。

### 发现一：一个教科书级的衰减偏误

同一份数据、同一个估计量，**只把自变量从会计口径的周度退货率换成订单级潜在倾向**：

| 口径 | λ₁ 估计值 | 相对误差 |
|---|---|---|
| 会计口径（`returns / orders`） | 0.038 | **97.1%** |
| 潜在口径（订单级概率） | 1.303 | 0.3% |

**衰减 97%，效应量相差 34 倍。**

原因：低单量周里，一个 SKU 卖 3 单、退 1 单就是 33% 退货率，退 0 单就是 0%——
分母过小的比率把大量二项抽样噪声混进了自变量。而测量误差不会让系数归零，
只会让它**系统性向零收缩**。

**实践含义**：任何"差评 → 流量/评分"的归因，都必须下沉到订单级或分母充足的粒度。
直接回归周度比率，会得出"差评无所谓"的错误结论。本项目走订单级 logit，
**这个技术选择有量化依据，不是风格偏好**。

### 发现二：一次把因果识别做坏、又救回来的修正

补偿档位最初用 `clip(0, 毛利×1.15)` 生成，结果补偿与毛利相关系数达 **0.209**，
¥50 档全部落在高客单 SKU 上。这会让人误判"补 ¥50 更有效"，
**实则"¥50 档的商品本身更贵更好卖"** —— 典型的遗漏变量混杂。

改为**分层随机试验**：新增 `exp_eligible` 标记，只在"毛利 ≥ ¥50、够得着全部 7 档"的
2,057 条可比样本上估计因果效应。该子集内 r(补偿, 毛利) = **−0.008**，完全正交。

结果：挽单率 24% → 68% 单调上升，但**期望利润在 ¥30 出现真实的内部最优**——
"补得越多越有效"和"补得越多越赚钱"是两件事。

## 已知局限（不藏）

| 局限 | 说明 |
|---|---|
| 传导系数为情景设定 | λ/ω 按"退货率 +5pp → DSR −0.065 分"的行业敏感度量级标定，但具体数值无公开数据可校准 |
| 补偿档位受毛利约束 | 只有毛利 ≥ ¥50 的 2,057 条能进入完整 7 档随机，全样本结论只能做描述性解读 |
| 文本语料跨品类混合 | 来自 4 个品类的公开语料，非单一店铺真实数据；应对方式是按类目分别报告 F1 |
| 未归因率 33.96% | 三成差评无法归类，是真实业务常态；作为主动学习闭环的输入，而非强行压低 |
| 退货损失口径 | 按成本（`cogs`）计提，非零售价。若按零售价会得单均 ¥79.39、占毛利 36.5%（偏大，已在缺陷记录 #20 说明理由） |

## 如何复核

在任何一台装了 Python 3 的机器上：

```bash
cd 03_脚本
python build_dataset.py        # 重建数据（约 30 秒）
python verify_transmission.py  # 参数回收检验
python audit_numbers.py        # 报告数字与数据核对
```
